核心能力

不只帮你写，
也帮你把故事写完整。

AI 负责起草与检查，你始终掌握最终决定。每一次修改都清晰可见，每一部作品都保存在自己的电脑里。

01

从设定到定稿

故事前提、世界观、人物、章节蓝图、正文、审稿与修稿形成完整流程，不必在多个工具之间来回切换。

02

长篇连续性账本

人物状态按章取值，伏笔按到期章节提醒，时间线与关系变化有据可查，减少越写越矛盾的问题。

03

统一技能中心

内置写作技能、智能体、子智能体与导入的 SKILL.md 集中管理，按规划、写稿、审稿和修稿阶段调用。

04

模型自由配置

填写兼容接口、API Key 与模型名称即可使用。可为不同创作阶段选择不同模型，也支持本地推理服务。

05

可审阅的智能体修改

智能体不会静默覆盖正文。修改以差异与建议呈现，由你逐项接受或拒绝，重要内容始终可控。

06

本地作品与开放格式

作品保存在本机，支持 Markdown 等开放格式。没有账号体系，也不需要把作品交给软件开发者。

常见问题

开始之前，你可能想知道。

可以直接调用 AI 自动写作吗？

可以。先在「自定义模型」中配置接口地址、API Key 和模型名称，再选择模型即可使用智能体写作、审稿与修稿。没有配置模型时，软件仍可作为本地编辑器使用。

作品和 API Key 会上传给开发者吗？

不会。作品保存在你的本地工作目录，模型密钥保存在当前电脑的用户数据目录。只有发起 AI 请求时，必要内容才会发送给你配置的模型服务。

换一台电脑安装，会带上原来的路径和数据吗？

不会。安装包不包含你的用户名、作品目录、模型密钥或用户配置。首次启动时会根据新电脑的用户目录重新生成默认位置。

支持哪些模型服务？

支持兼容 OpenAI、Anthropic 与 Google 协议的服务，也可配置本地推理接口。具体可用性取决于你选择的服务商和模型。

适合写长篇小说吗？

适合。章节蓝图、人物状态时间线、伏笔到期提醒和连续性账本专为跨章节创作设计，可减少前后矛盾与线索遗漏。

生成内容可以直接商用或发布吗？

需要作者自行核实事实、原创性与素材授权，并遵守对应平台和地区的规则。软件不对生成内容作版权保证。
